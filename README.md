# MathNote (PHP translation)

This repository is an initial PHP + HTML/CSS/JS translation of the original MathNote project.

How to run (development):

1. Clone repo
2. From the project root run:

   php -S localhost:8000

3. Open http://localhost:8000

Notes:
- Simple storage is data/notes.json (no database). For production use a proper DB.
- This is an initial scaffold. I will continue translating other features from the original React/Node project on request.
